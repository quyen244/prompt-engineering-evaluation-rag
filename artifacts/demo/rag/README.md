# RAG end-to-end demo

`rag-e2e-demo.mp4` records a live browser session against the local React frontend and FastAPI service.
The session uses all 100 indexed TechQA documents, asks evaluation question `DEV_Q244`, retrieves one passage, and displays the generated answer with its source evidence.
The video includes the actual wait for local inference and is not a simulated response.

The three PNG files show the indexed corpus, submitted question, and answer with source evidence.
This is a product-flow demo, not a new evaluation score or a concurrency benchmark.
